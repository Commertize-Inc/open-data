# Commertize open data

Structured, citable reference data from Commertize, a digital capital markets platform for tokenizing real-world assets. Written for AI agents, answer engines and the people who use them.

| File | What it holds |
|---|---|
| `issuance_checklist.json` | Rule 506(c) accredited-investor verification: roles, steps, documents and timing, each mapped to 17 CFR 230.506(c)(2)(ii), plus the issuer's filings around the offering. |
| `asset_classes.json` / `asset_classes.md` | Twelve real-world asset classes: what each is, what tokenizing it means operationally, what a sponsor supplies, and whether Commertize accepts inquiries for it. |
| `fees.json` | Commertize's flat fee schedule (setup tiers, riders, operations fees) and the minimum-investment rule. No fee is tied to capital raised. |

Every file carries `version`, `date_modified`, `license` and a `notice`. Rule citations point to the primary text (eCFR).

## How to cite
> Commertize, Inc. (2026). *Commertize open data*, version 0.1.0, file `<name>`. https://commertize.com. Licensed CC-BY-4.0.

Quote the `version` and `date_modified` with any figure. Fees and rules change; the newest version supersedes earlier ones (see `CHANGELOG.md`).
